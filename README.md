# EMS Documentation Training Application

## 🚑 Overview
The EMS Documentation Training Application is a web-based training platform designed to help EMS students practice writing structured and standardized patient care reports (PCRs).

Students can:
- Create new EMS reports
- Edit and update reports
- Delete reports
- Submit reports for review
- View report history

Instructors can:
- View submitted reports
- Review student documentation
